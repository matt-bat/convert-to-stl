# Changelog

## 1.0.0 — 2026-10-03

Initial public release. Original implementation and release prepared for Matt Bateman.

- Native Windows x64 desktop converter with a portable bundled runtime.
- 3MF, STEP/STP, IGES/IGS, OBJ, PLY, OFF, GLB/GLTF, basic AMF, and STL input.
- Explicit batch conversion with preserved originals and collision-safe outputs.
- CAD detail presets, mesh-unit selection, selected-folder output, Stop and retry.
- Translucent pastel studio interface with adaptive settings and keyboard controls.
- Source tests, packaged conversion checks, sample models, and build scripts.
