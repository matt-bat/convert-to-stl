# Contributing

Read [LICENSE](LICENSE) and [development](docs/DEVELOPMENT.md) before contributing.
Contributions must be yours to submit under this project's terms; do not include
third-party models, proprietary files, or credentials without permission.

For bugs, provide the version, format, expected behavior, exact error, and a
minimal model you can share. Generated fixtures are preferred. For changes,
explain the behavior and add a regression test where useful. Preserve explicit
manual start, source files, output-collision protection, units, and offline
conversion. Run the test suite and the relevant packaged checks. Update docs
for user-visible or build changes and describe major modifications in the changelog.

Pull requests should be focused and include validation results. Do not commit
environments, build outputs, personal screenshots, local file paths, or binaries
intended for release downloads. Issues and pull requests are public.
